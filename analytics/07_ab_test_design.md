# A/B 테스트 설계 문서 — 고위험 고객 대상 리텐션 실험 2건

> **중요**: 이 문서는 **실험 설계안**이다. KKBox 실서비스에 접근할 수 없어 실제로 실험을 진행하거나
> 결과를 관측한 적이 없다. 이 문서에 나오는 수치는 (1) 우리 데이터로 실제 계산한 것(베이스라인 잔존율,
> 필요 표본수)과 (2) 아직 검증되지 않은 가설(기대 효과 크기)을 명확히 구분해서 표기한다. "예상 결과"를
> 실제 실험 결과처럼 제시하지 않는다.

## 1. 배경

`analytics/06_customer_segmentation.ipynb`에서 LightGBM + SHAP로 고위험 고객(예측 이탈확률 ≥ 0.326)을
찾고, 이들을 이탈 위험을 가장 크게 밀어올린 개별 피처 기준으로 세분화했다. 그 중 두 세그먼트가
전체 고위험군의 약 80%를 차지하며, 둘 다 개입 시점이 명확하고 실행 가능한 액션이 뚜렷해서 각각
별도의 A/B 테스트 대상으로 삼았다:

| 세그먼트 | 비중 | 특징 | 대응 실험 |
|---|---|---|---|
| 마지막 결제 이후 경과일(`days_since_last_txn`) 큼 | 42.7% | 이미 결제가 끊긴 지 오래된 고객 | 실험 B (윈백) |
| 만료 임박(`days_to_expire`) | 37.1% | 곧 멤버십이 만료되는 고객 | 실험 A (갱신 리마인드) |

**가치(LTV) 축 반영**: `analytics/04_ltv.ipynb`에서 이탈확률(위험)과 월평균매출(가치, 중앙값 142.1 NTD)을
독립된 두 축으로 나눠 "고위험×고가치"(93,912명) / "고위험×저가치"(31,670명) 세그먼트를 이미 계산해뒀다.
리소스가 제한적인 실무 상황을 가정해, 두 실험 모두 **고위험×고가치 교집합을 1차 우선순위 모집단**으로,
고위험×저가치를 2차 확장 대상으로 둔다 — 위험도만 보고 가치를 무시하면 리텐션 액션의 ROI가 낮아지기
때문이다.

## 2. 실험 A — 만료 임박 갱신 리마인드

### 2-1. 가설

> 멤버십 만료 7일 전, 예측 이탈확률이 높은(≥0.326) 고객에게 갱신 리마인드 알림을 보내면, 만료 후
> 30일 이내 재구독률이 대조군보다 높을 것이다. 추가로, 리마인드에 소폭 할인 프로모션을 더하면
> 리마인드 단독보다 재구독률이 한 번 더 오를 것이다.

이 가설은 **상관관계 기반 관찰(SHAP: 만료 임박이 이탈확률을 높이는 방향으로 크게 기여)에서 나온
가설이며, 인과관계가 증명된 것은 아니다.** A/B 테스트의 목적이 바로 이 가설의 인과성을 검증하는 것이다.

### 2-2. 실험 설계 (3-arm)

| 항목 | 내용 |
|---|---|
| **모집단(1차 우선순위)** | 멤버십 만료 7일 전 + 예측 이탈확률 ≥ 0.326 + **고위험×고가치**(월평균매출 ≥ 142.1 NTD) 고객 |
| **모집단(2차 확장)** | 위 조건 충족 + 고위험×저가치 고객까지 포함 (표본 여유가 있을 때 확장) |
| **Control** | 기존과 동일한 서비스 경험 (알림 없음) |
| **Treatment 1** | 만료 7일 전 갱신 리마인드 알림만 발송 |
| **Treatment 2** | 갱신 리마인드 알림 + 소폭 할인 프로모션 발송 |
| **배정 방식** | 고객 단위 랜덤 배정, **가치 축(고가치/저가치)을 층화 변수로 사전 층화**해 세 그룹에 균형 배정 (유저가 여러 결제 주기를 거치며 반복 노출되지 않도록 최초 배정 유지) |
| **Primary KPI** | 만료 후 30일 이내 재구독률 (`is_churn=0` 비율과 동일한 정의) |
| **Secondary KPI** | 리마인드 발송 후 7일 이내 앱 재방문율, 리마인드/프로모션 클릭률, (Treatment 2만) 프로모션 사용률·할인 대비 순증 매출 |
| **Guardrail** | 알림 수신거부율, 앱 삭제/탈퇴율 — 이 지표가 유의미하게 악화되면 실험 중단 |
| **실험 기간** | 최소 1개 만료 주기(약 30일) + 결과 집계 30일 = 총 약 60일 |

### 2-3. 샘플사이즈 (실제 계산값)

베이스라인 잔존율은 우리 라벨 데이터 전체 기준 **92.3%**(이탈률 7.7%)를 사용했다. 두 비율 z-검정
(power=0.80)으로 최소 탐지 효과(MDE)별 필요 표본수는 다음과 같다 (실제 계산, `scipy.stats` 사용):

| 최소 탐지 효과(MDE) | Control 잔존율 | Treatment 잔존율(가정) | 그룹당 필요 표본수 (α=0.05) | 그룹당 필요 표본수 (α=0.025, 3-arm 보정)† |
|---|---|---|---|---|
| +1%p | 92.3% | 93.3% | 10,488명 | 12,698명 |
| +2%p | 92.3% | 94.3% | 2,453명 | 2,967명 |
| +3%p | 92.3% | 95.3% | 1,014명 | 1,224명 |

† Treatment가 2개(리마인드만 / 리마인드+할인)로 늘어나 Control과 각각 비교(pairwise)하므로, 다중비교
보정을 위해 Bonferroni 방식으로 유의수준을 α=0.05 → **α/2=0.025**로 보정했다. 이 경우 필요 표본수가
약 1.2배 늘어난다. 3-arm이므로 전체 필요 표본수는 (그룹당 표본수) × 3이다.

"만료 임박" 세그먼트가 고위험군의 37.1%였으므로(샘플 396명 중 147명), 실제 모집단(라벨 코호트
108만명 규모)에서는 이 표본수를 확보하는 것 자체는 어렵지 않을 것으로 예상되나, **이는 표본 크기의
통계적 요건일 뿐이며, 위 표의 "Treatment 잔존율"은 검증되지 않은 가정값이지 예측치가 아니다.**

## 3. 실험 B — 장기 미결제 고객 대상 윈백(Win-back) 캠페인

### 3-1. 배경 및 실제 베이스라인 계산

고위험군의 42.7%(실험 A의 37.1%보다 큰 세그먼트)를 차지하는 "장기 미결제"(`days_since_last_txn` 큼)
고객은 지금까지 어떤 실험 설계 대상도 아니었다. `data/processed/model_table_final.csv`(라벨 있는
전체 풀링 데이터, 1,963,891행)를 실제로 조회한 결과:

| 마지막 결제 후 경과일 | 해당 유저 비중 | 실제 관측 재구독(잔존)률 |
|---|---|---|
| ≥ 30일 | 6.8% | 44.7% |
| **≥ 60일 (윈백 트리거 기준)** | **2.8%** | **28.4%** |
| ≥ 90일 | 2.5% | 28.0% |
| ≥ 120일 | 2.3% | 27.0% |

**60일 이상 미결제**를 윈백 캠페인의 운영 트리거로 채택했다 — 이미 실험 A의 베이스라인(92.3%)과는
비교가 안 될 정도로 잔존률이 낮아(28.4%), 실험 A보다 훨씬 심각하게 이탈이 진행된 고객군임을 실제
데이터로 확인했다.

### 3-2. 가설

> 마지막 결제 후 60일 이상 경과 + 예측 이탈확률이 높은(≥0.326) 고객에게 개인화된 윈백 메시지(청취
> 이력 기반 추천 콘텐츠 + 재구독 유도)를 보내면, 발송 후 30일 이내 재구독률이 대조군보다 높을 것이다.
> 할인 프로모션을 더하면 한 번 더 오를 것이다.

이 가설 역시 SHAP 상관관계 기반 관찰에서 나온 가설이며 인과관계가 증명된 것은 아니다.

### 3-3. 실험 설계 (3-arm)

| 항목 | 내용 |
|---|---|
| **모집단(1차 우선순위)** | 마지막 결제 후 60일 이상 경과 + 예측 이탈확률 ≥ 0.326 + **고위험×고가치** 고객 |
| **모집단(2차 확장)** | 위 조건 충족 + 고위험×저가치 고객까지 포함 |
| **Control** | 기존과 동일한 서비스 경험 (메시지 없음) |
| **Treatment 1** | 개인화 윈백 메시지만 발송 (청취 이력 기반 추천 + 재구독 유도) |
| **Treatment 2** | 윈백 메시지 + 할인 프로모션 발송 |
| **배정 방식** | 고객 단위 랜덤 배정, 가치 축(고가치/저가치)을 층화 변수로 사전 층화 |
| **Primary KPI** | 발송 후 30일 이내 재구독률 |
| **Secondary KPI** | 메시지 클릭률, 앱 재방문율, (Treatment 2만) 프로모션 사용률·순증 매출 |
| **Guardrail** | 수신거부율, 탈퇴율 — 실험 A와 동일 기준 |
| **실험 기간** | 발송 후 결과 집계 30일 |

### 3-4. 샘플사이즈 (실제 계산값)

베이스라인 28.4%(위 3-1 실측값) 기준, 두 비율 z-검정(power=0.80)으로 계산한 필요 표본수:

| 최소 탐지 효과(MDE) | Control 잔존율 | Treatment 잔존율(가정) | 그룹당 필요 표본수 (α=0.05) | 그룹당 필요 표본수 (α=0.025, 3-arm 보정) |
|---|---|---|---|---|
| +5%p | 28.4% | 33.4% | 1,337명 | 1,619명 |
| +10%p | 28.4% | 38.4% | 346명 | 419명 |
| +15%p | 28.4% | 43.4% | 157명 | 190명 |

베이스라인이 낮아 실험 A보다 더 큰 %p 단위의 MDE를 사용했다(잔존률 자체가 낮으니 절대적으로 큰
변화를 노리는 것이 현실적). 전체 모집단(라벨 코호트 약 108만명) 중 60일 이상 미결제 비중이 2.8%이므로
전체 대상 규모는 약 30,300명으로 추정되며(실제 계산: 108만명 × 2.8%), 위 표본수 대비 충분히 여유가
있다. 단, **"Treatment 잔존율" 열은 검증되지 않은 가정값**이다.

## 4. 분석 계획 (실험 A·B 공통)

- Primary KPI는 카이제곱 검정 또는 두 비율 z-검정으로 유의성 판단. 3-arm이므로 Control 대비 Treatment
  1, Treatment 2 각각의 비교에 Bonferroni 보정(α=0.025)을 적용한다.
- 가치 축(고가치/저가치)은 **사전 층화 변수**로 무작위 배정 단계에서부터 반영해 그룹 간 가치 분포가
  균형 잡히도록 한다(사후 보정이 아니라 사전 설계).
- 추가로 결제 이력(과거 결제액, tenure 등)으로 사후 계층화(stratification)해 이질적 처치 효과(HTE)
  탐색 가능.
- Guardrail 지표는 방향과 무관하게 사전에 정한 허용 범위를 벗어나면 실험 조기 중단.

## 5. 한계 및 주의사항

- **실행하지 않은 설계안**이다. 실제 발송 시스템, 알림 인프라, 프로모션 예산 등은 이 문서 범위 밖.
- 실험 A의 베이스라인 잔존율(92.3%)과 실험 B의 베이스라인(28.4%)은 2015~2017년 과거 데이터 기준이며
  현재 KKBox 상황과 다를 수 있다.
- 실험 B의 "60일 이상 미결제" 컷오프는 실측 데이터를 참고해 정한 운영상 트리거일 뿐, 여러 컷오프 후보
  중 최적값을 검증한 것은 아니다.
- SHAP 기반으로 도출한 가설이라 인과관계가 아닌 상관관계에서 출발했음을 항상 함께 명시해야 한다.
- 3-arm으로 확장하면서 총 필요 표본수는 대조군 1개 + 처치군 2개, 즉 그룹당 표본수의 약 3배가 필요하다.
